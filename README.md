## What it does

`main.py` (stdlib-only Python) writes a single word to `/output/entry.txt`:
the one-word verdict on an ex that won the sparring rounds against the
judge's published brief — instantly readable as a verdict on a former
partner, with comic punch, surprise, craft and recognition. The word is
**Placeholder**: they kept the seat warm until the real one arrived.

The program keeps a shortlist of candidate words, each scored against the
judge's criteria, and writes out the highest-scoring one.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
